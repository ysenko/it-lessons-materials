# Інструкція з використання `nit_grade_calculator.ipynb`

Цей ноутбук обробляє Excel-файл з оцінками учнів, рахує підсумкові показники за критеріями та експортує результат у новий Excel-файл.

## Що робить ноутбук

- Зчитує вхідний Excel-файл з журналом оцінок.
- Визначає колонки критеріїв `1`, `2`, `3`, `4` за значеннями у 3-му рядку таблиці.
- Використовує колонку B як ПІБ/ім'я учня.
- Рахує для кожного учня:
  - `Кількість оцінок 1..4`
  - `Середня 1..4`
  - `Семестрова = (Середня 1 + Середня 2 + Середня 3 + Середня 4) / 4`
    (якщо для певного критерію оцінок немає, його середня вважається `0` у цій формулі).
- Експортує результат у `.xlsx` та підсвічує червоним:
  - `Кількість оцінок X`, якщо вона дорівнює `0`
  - відповідну `Середня X`, якщо `Кількість оцінок X = 0`
- Формує назву файлу у форматі:
  - `Зведені оцінки <клас> - <група>.xlsx`

## Підготовка

1. Відкрийте ноутбук `nit_grade_calculator.ipynb` у Google Colab.
2. Підготуйте вхідний Excel-файл (експорт з НІТ), наприклад:
   - `Журнал класу_Січень 2026-Березень 2026, 8-А, група 1, Інформатика.xlsx`

## Покрокове виконання

1. Запустіть **Крок 1 (комірка 1)**:
   - встановлюються залежності: `polars`, `fastexcel`, `xlsxwriter`.
2. Запустіть **Крок 2 (комірка 4)**:
   - з'явиться вікно завантаження файлу.
   - завантажте свій Excel-файл з оцінками.
3. Запустіть **Крок 3 (комірка 7)**:
   - ноутбук обчислить показники по кожному учню.
   - унизу комірки буде показано таблицю `result`.
4. Запустіть **Крок 4 (комірка 8)**:
   - ноутбук згенерує Excel-файл із форматуванням.
   - файл автоматично завантажиться на ваш комп'ютер.

## Структура вихідного файлу

У вихідному Excel-файлі будуть колонки:

1. `Учень`
2. `Кількість оцінок 1`
3. `Середня 1`
4. `Кількість оцінок 2`
5. `Середня 2`
6. `Кількість оцінок 3`
7. `Середня 3`
8. `Кількість оцінок 4`
9. `Середня 4`
10. `Семестрова`

## Поради та типові проблеми

- Якщо бачите помилку, що `result` не визначено:
  - спочатку запустіть комірку 7, а потім комірку 8.
- Якщо бачите помилку, що `scores_file_path` не визначено:
  - спочатку запустіть комірку 4 та завантажте файл.
- Якщо змінили код і хочете перерахунок:
  - запустіть комірки 4, 7, 8 повторно у цьому порядку.

## Вимоги до вхідного файлу

- У 3-му рядку мають бути позначки критеріїв `1`, `2`, `3`, `4`.
- У колонці B мають бути імена учнів.
- Оцінки мають бути числовими (або порожніми).
