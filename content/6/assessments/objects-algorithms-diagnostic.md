## Група 1: Працює з інформацією, даними, моделями

### Рівень: Простий

**1.** Модель — це…

- А) точна копія об'єкта без жодних спрощень
- Б) спрощене подання предмета, явища чи процесу
- В) будь-яка комп'ютерна програма
- Г) схема роботи алгоритму

**2.** За способом подання виділяють такі типи моделей:

- А) словесні, графічні, математичні та табличні
- Б) матеріальні, інформаційні та комп'ютерні
- В) прості, складні та дуже складні
- Г) точні, наближені та умовні

**3.** Формула S = V × t є прикладом якої форми подання інформаційної моделі?

- А) Графічної
- Б) Табличної
- В) Математичної
- Г) Словесної

**4.** Який крок є першим під час проведення комп'ютерного експерименту?

- А) Аналіз результатів
- Б) Постановка задачі
- В) Побудова комп'ютерної моделі
- Г) Тестування моделі

**5.** Що таке алгоритм?

- А) Таблиця даних для вирішення задачі
- Б) Назва комп'ютерної мови програмування
- В) Точна послідовність кроків для розв'язання задачі
- Г) Схема класифікації об'єктів

### Рівень: Середній

**6.** Зіставте поняття з їх описом:

| Поняття | Опис |
|---------|------|
| А. Матеріальна модель | 1. Відтворює фізичні властивості об'єкта (глобус, макет будівлі) |
| Б. Інформаційна модель | 2. Сукупність відомостей про об'єкт (опис, схема, формула) |
| В. Розгалуження | 3. Структура алгоритму, що виконує різні дії залежно від умови |
| Г. Цикл | 4. Структура алгоритму, що повторює дії певну кількість разів |

## Група 3: Працює в цифровому середовищі

### Рівень: Простий

**8.** У якій категорії Scratch містяться блоки для переміщення спрайта по екрану?

- А) Вигляд
- Б) Рух
- В) Керування
- Г) Змінні

**9.** Яка подія в Scratch запускає скрипт у момент натискання зеленого прапорця?

- А) «Коли натиснуто цей спрайт»
- Б) «Коли я отримаю повідомлення»
- В) «Коли натиснуто клавішу»
- Г) «Коли натиснуто зелений прапорець»

**10.** Що таке змінна у Scratch?

- А) Блок для зміни координат спрайта
- Б) Поіменоване місце у пам'яті для зберігання даних
- В) Тип спрайта з особливими властивостями
- Г) Команда для зміни костюма спрайта

**11.** Яке середовище використовується для програмування Micro:Bit?

- А) Scratch
- Б) MakeCode
- В) Microsoft Word
- Г) Google Таблиці

**12.** Що відбувається при виконанні блоку «повторити 5 разів» у Scratch?

- А) Програма зупиняється 5 разів
- Б) Команди всередині блоку виконуються рівно 5 разів
- В) Програма запускається спочатку 5 разів
- Г) Спрайт змінює костюм 5 разів

## Група 4: Безпечно та відповідально використовує ІТ

### Рівень: Простий

**15.** Що таке робот?

- А) Комп'ютерна програма, що виконує обчислення
- Б) Пристрій, здатний виконувати дії автоматично або за програмою
- В) Будь-який пристрій із дистанційним керуванням
- Г) Будь-який електричний прилад

**16.** Який компонент робота виконує роль «мозку» — обробляє дані та приймає рішення?

- А) Датчик / сенсор
- Б) Маніпулятор
- В) Мікроконтролер
- Г) Акумулятор

**17.** У яких сферах застосовуються роботи?

- А) Тільки в іграшковій промисловості
- Б) Виключно в космосі та авіації
- В) У медицині, промисловості, космосі та побуті
- Г) Лише на підприємствах із небезпечними умовами праці

**18.** Чому безпечніше тестувати небезпечні об'єкти за допомогою комп'ютерних моделей?

- А) Моделі завжди дають точніші результати, ніж реальні об'єкти
- Б) Це дозволяє уникнути реальних витрат і ризиків
- В) Моделі не потребують ніяких знань для роботи
- Г) Реальні об'єкти не можна досліджувати іншими способами

**19.** Що таке робототехніка?

- А) Програмне забезпечення для керування Micro:Bit
- Б) Галузь науки і техніки, що займається проектуванням, створенням та застосуванням роботів
- В) Методика програмування у Scratch
- Г) Технологія передачі даних між комп'ютерами
