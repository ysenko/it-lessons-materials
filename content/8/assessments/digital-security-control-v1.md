**3.** Програмою можна користуватися безкоштовно, але змінювати й поширювати її заборонено (наприклад, безкоштовна версія Zoom). До якого типу належить така програма? *(оберіть одну відповідь)*

- [ ] Б) Брандмауер знаходить і видаляє віруси, які вже потрапили на комп'ютер

- [ ] Д) Для кращого захисту варто встановити одночасно два антивіруси із захистом у реальному часі
- [ ] Е) Усі перелічені

**8.** Які твердження про видалення та відновлення даних правильні? *(оберіть усі правильні варіанти)*

- [ ] А) Видалення клавішами Shift+Delete знищує файл фізично, тому відновити його неможливо
- [ ] Б) Після очищення Кошика файл залишається на диску, доки його місце не займуть інші дані
- [ ] В) Відновлений файл бажано зберігати на інший носій, щоб не перезаписати дані, які рятують
- [ ] Г) Програма Recuva може відновити будь-який файл, навіть після безпечного перезапису (Secure Overwrite)
- [ ] Д) Перед продажем комп'ютера конфіденційні файли варто видаляти програмами, що багаторазово перезаписують місце на диску (Eraser, File Shredder)
