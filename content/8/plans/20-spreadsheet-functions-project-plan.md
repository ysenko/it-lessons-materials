**Тема:** Навчальний проєкт «Благодійний ярмарок»: опрацювання табличних даних з використанням функцій
**Тип уроку:** Урок узагальнення та систематизації знань (навчальний проєкт, індивідуально або в парах)

## Мета уроку

**Навчальна:** узагальнити та застосувати знання уроку 19 про вбудовані функції табличного процесора: математичні (SUM, ROUND, MOD), статистичні (AVERAGE, MAX, MIN, RANK), COUNTIF, повторити призначення фінансової функції FV; закріпити вміння самостійно створювати електронну таблицю, вводити формули й функції, застосовувати автозаповнення з відносними та абсолютними посиланнями.

**Розвивальна:** розвивати вміння добирати функцію відповідно до задачі, аналізувати результати обчислень і робити з них висновки, планувати власну роботу та співпрацювати в парі.

**Виховна:** виховувати фінансову грамотність, ініціативність і соціальну відповідальність (благодійність), охайність і точність під час роботи з даними.

2. **Завдання 1 — теоретична частина: тест Classtime (7 хв, до 6 балів)**

Кожне запитання — 1 бал, лише за повністю правильну відповідь; максимум 6 балів. Після завершення часу вчитель закриває сесію; результати Classtime підраховує автоматично.

   **Підготовка вчителя:**
   1. Увійти на https://www.classtime.com (обліковий запис учителя — безкоштовний).
   2. *Бібліотека* → *Створити набір запитань* → назва «8 клас. Урок 20. Повторюємо функції».
   3. Додати 6 запитань (нижче) зазначених типів, позначити правильні відповіді, для кожного запитання встановити 1 бал і вимкнути часткове зарахування (для співставлення та кількох правильних відповідей).
   4. *Розпочати сесію* → увімкнути вхід без реєстрації (учні вводять лише ім'я) → код сесії повідомити учням на уроці (на слайді Завдання 1 — лише загальне посилання на сайт Classtime для приєднання).

   **Готовий зміст запитань (правильні відповіді виділено):**

   1. *(Співставлення)* Співставте задачу ярмарку з функцією:
      - Загальна виручка — **SUM**
      - Середня ціна товару — **AVERAGE**
      - Найменша кількість проданих товарів — **MIN**
      - Місце товару в рейтингу продажів — **RANK**
   2. *(Одна правильна відповідь)* Який результат формули `=ROUND(27,125; 1)`?
      - 27
      - **27,1**
      - 27,13
      - 27,2
   3. *(Одна правильна відповідь)* Продали 41 склянку лимонаду, з одного глека виходить 6 склянок. Скільки склянок налили з останнього неповного глека? Яка формула це обчислює?
      - **`=MOD(41; 6)` → 5**
      - `=MOD(6; 41)` → 6
      - `=ROUND(41/6; 0)` → 7
      - `=41/6` → 6,83
   4. *(Одна правильна відповідь)* Формулу `=RANK(D2; D2:D9; 0)` скопіювали автозаповненням униз. Чому місця вийшли неправильні?
      - Треба було написати 1 замість 0
      - **Діапазон треба записати з абсолютним посиланням: `$D$2:$D$9`**
      - RANK не можна копіювати
      - Треба було використати MAX
   5. *(Одна правильна відповідь)* Яка формула порахує, скільки товарів продали в кількості 20 штук і більше (кількість — у `C2:C9`)?
      - `=COUNT(C2:C9)`
      - `=SUM(C2:C9; ">=20")`
      - **`=COUNTIF(C2:C9; ">=20")`**
      - `=MAX(C2:C9)`
   6. *(Кілька правильних відповідей)* Що правильно про функцію `FV(ставка; періодів; платіж)`?
      - **Обчислює, скільки грошей буде на рахунку через певний час**
      - **Якщо внески щомісячні, річну ставку ділять на 12**
      - **Суму внеску записують зі знаком мінус, щоб результат був додатним**
      - Обчислює щомісячний платіж за кредитом

3. **Завдання 2 — практична частина: таблиця «Благодійний ярмарок» (25 хв, до 6 балів)**

   **Інструктаж (3 хв).** Учні працюють індивідуально або в парах. Пара створює одну таблицю: один учень створює файл і надає доступ партнерові (*Поділитися* → ввести адресу → *Редактор*); працюють по черзі, обидва вводять формули. Назва файлу — `Урок20_Ярмарок_Прізвище` (для пари — `Урок20_Ярмарок_Прізвище1_Прізвище2`). Вчитель оголошує критерії оцінювання (слайд). Кожне наступне завдання виконується в тій самій таблиці.

   **Виконання (22 хв, на 11-й хвилині — релаксація для очей).**

   Таблиця, яку учні створюють (дані вводять з презентації). Порожні клітинки учні заповнюють **лише формулами та функціями**; клітинки з «—» залишаються порожніми.

   |  | A | B | C | D | E | F | G | H |
   |---|---|---|---|---|---|---|---|---|
   | **1** | **Товар** | **Ціна, грн** | **Продано, шт** | **Виручка, грн** | **Місце** | **Частка, %** | Товарів, проданих від 20 шт | |
   | **2** | Імбирне печиво | 15 | 48 | | | | Товарів з виручкою від 700 грн | |
   | **3** | Кекс | 25 | 32 | | | | Склянок з неповного глека | |
   | **4** | Лимонад (склянка) | 20 | 41 | | | | | |
   | **5** | Брелок ручної роботи | 40 | 12 | | | | Товарів з часткою понад 10 % | |
   | **6** | Листівка | 10 | 27 | | | | | |
   | **7** | Закладка для книжки | 12 | 19 | | | | | |
   | **8** | Ароматична свічка | 60 | 7 | | | | | |
   | **9** | Браслет | 35 | 15 | | | | | |
   | **10** | **Разом** | — | | | — | — | | |
   | **11** | **Середнє** | | | | — | — | | |
   | **12** | **Найбільше** | | | | — | — | | |
   | **13** | **Найменше** | | | | — | — | | |

   Клітинки, які заповнюють учні: `D2:D9` (виручка), `C10:D10` (разом), `B11:D13` (середнє, найбільше, найменше), `E2:E9` (місце), `H1:H3` (COUNTIF, MOD), `F2:F9` (частка виручки), `H5` (COUNTIF за часткою).

   На слайдах завдань назви функцій не вказано — учні добирають їх самостійно; на кожному слайді наголошено: **усі обчислення виконувати лише за допомогою функцій**.

   **Середній рівень (1 бал):**
   1. Створити таблицю, ввести дані та заголовки, оформити її (жирні заголовки, межі, ширина стовпців).
   2. У `D2` обчислити виручку за товар (функція PRODUCT) і скопіювати маркером автозаповнення до `D9`.
   3. У рядку *Разом* за допомогою функції обчислити загальну кількість проданих товарів і загальну виручку (`C10`, `D10`, функція SUM).
   4. У рядках *Середнє* (з округленням до десятих), *Найбільше*, *Найменше* за допомогою функцій обчислити значення для стовпців B, C, D (функції ROUND, AVERAGE, MAX, MIN; формулу записати в стовпці B і скопіювати вправо).

   **Достатній рівень (2 бали):**
   5. У стовпці *Місце* за допомогою функції визначити рейтинг товарів за виручкою (найбільша виручка — 1 місце); формулу записати один раз у `E2` і скопіювати автозаповненням. *(1 бал)*
   6. У клітинках `H1:H3` за допомогою функцій обчислити: скільки товарів продали в кількості 20 шт і більше; скільки товарів дали виручку від 700 грн; скільки склянок лимонаду налили з останнього неповного глека, якщо з глека виходить 6 склянок. *(1 бал)*

   **Високий рівень (3 бали):**
   7. У стовпці *Частка, %* обчислити, яку частку (у відсотках) загальної виручки дав кожен товар, з округленням до десятих; формулу записати один раз у `F2` і скопіювати автозаповненням. *(2 бали)*
   8. У `H5` обчислити, скільки товарів дали понад 10 % загальної виручки. *(1 бал)*

   **Очікувані формули та відповіді для вчителя** (перевірено обчисленням; роздільник аргументів — `;`, мовний стандарт *Україна*):
   - *Виручка:* `=PRODUCT(B2:C2)` → `D2:D9` — 720, 800, 820, 480, 270, 228, 420, 525.
   - *Разом:* `=SUM(C2:C9)` → 201; `=SUM(D2:D9)` → 4 263.
   - *Середнє:* `=ROUND(AVERAGE(B2:B9); 1)` → 27,1; стовпець C → 25,1; стовпець D → 532,9.
   - *Найбільше:* 60; 48; 820. *Найменше:* 10; 7; 228.
   - *Місце:* `=RANK(D2; $D$2:$D$9; 0)` → 3, 2, 1, 5, 7, 8, 6, 4 (лимонад — 1, кекс — 2, печиво — 3).
   - `H1`: `=COUNTIF(C2:C9; ">=20")` → 4; `H2`: `=COUNTIF(D2:D9; ">=700")` → 3; `H3`: `=MOD(C4; 6)` → 5.
   - *Частка, %:* `=ROUND(D2/$D$10*100; 1)` → 16,9; 18,8; 19,2; 11,3; 6,3; 5,3; 9,9; 12,3 (без `$` у `$D$10` після автозаповнення з'являється помилка ділення на порожню клітинку).
   - `H5`: `=COUNTIF(F2:F9; ">10")` → 5.

   **Перевірка роботи.** Вчитель перевіряє та оцінює роботи під час уроку безпосередньо на робочих місцях учнів: учень (пара) повідомляє про завершення рівня, вчитель переглядає формули в клітинках (рядок формул) і за потреби просить пояснити одну з них. Здавати файл чи надсилати посилання не потрібно. Поза перевіркою вчитель консультує лише з технічних питань.

   **Примітки для вчителя:** якщо формула з `;` видає помилку — у таблиці англійський мовний стандарт: *Файл → Налаштування → Мовний стандарт → Україна* (або замінити `;` на `,`). Якщо учень не може увійти в обліковий запис Google — виконує роботу в Excel і зберігає файл у теці *Документи*.

   ### Критерії оцінювання

   **Теоретична частина (Завдання 1) — до 6 балів:** по 1 балу за кожне з 6 запитань тесту Classtime (лише повністю правильна відповідь).

   **Практична частина (Завдання 2) — до 6 балів:**

   | Рівень | Умова зарахування | Бали |
   |---|---|---|
   | Середній | 1–4: таблицю створено й оформлено, виручку обчислено функцією PRODUCT з автозаповненням, правильно застосовано SUM, ROUND, AVERAGE, MAX, MIN (усі пункти рівня) | 1 |
   | Достатній | 5: правильний рейтинг RANK з абсолютним посиланням — 1 бал; 6: правильні COUNTIF з умовами та MOD — 1 бал | 2 |
   | Високий | 7: правильно обчислено частку виручки з ROUND та абсолютним посиланням — 2 бали; 8: правильний COUNTIF за часткою — 1 бал | 3 |

   Бал за завдання зараховується, лише якщо результат обчислено **за допомогою функції** (а не введено вручну).

   **Підсумкова оцінка** — сума балів теоретичної та практичної частин (максимум 12). Робота в парі: за практичну частину обидва учні отримують однакову кількість балів, але кожен на прохання вчителя має пояснити будь-яку формулу з таблиці; якщо учень не може пояснити — бал за практичну частину для нього знижується на 1–2 бали.

4. **Підбиття підсумків та рефлексія (7 хв)**

   - Обговорення: «Яка функція знадобилася найчастіше?», «Що станеться з усіма результатами, якщо змінити ціну кексу?» *(усі функції переобчисляться автоматично — у цьому перевага функцій над ручними обчисленнями)*, «Де помилки траплялися найчастіше?» *(абсолютне посилання в RANK і в частці виручки)*.
