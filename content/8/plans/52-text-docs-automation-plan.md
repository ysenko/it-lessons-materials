# План уроку №52

**Тема:** Автоматизовані засоби опрацювання текстових документів. Створення колонок, розділів у текстовому документі. Колонтитули.
**Клас:** 8
**Тип уроку:** Урок засвоєння нових знань

## Мета уроку:
*   **Навчальна:** навчити учнів практичним навичкам керування структурою документа: розбиттю тексту на колонки, управлінню розділами для зміни орієнтації сторінок, додаванню колонтитулів та автоматичної нумерації.
*   **Розвивальна:** розвивати вміння працювати за алгоритмом, увагу до деталей інтерфейсу хмарних сервісів.
*   **Виховна:** формувати навички професійного оформлення текстових робіт (рефератів, звітів, газет).

## Хід уроку:

### I. Організаційний етап (2 хв)
*   БЖД, перевірка готовності.

### II. Актуалізація (3 хв)
*   Питання: "Як змінити орієнтацію всієї сторінки?" та "Чи можна змінити орієнтацію лише для одного аркуша посеред документа?".

### III. Вивчення нового матеріалу (покроково) (20 хв)

#### 1. Створення розділів (Sections)
*   **Навіщо:** щоб мати різні поля або орієнтацію в одному файлі.
*   **Крок:** `Вставити` -> `Розрив` -> `Розрив розділу (наступна сторінка)`.

#### 2. Текст у кілька колонок
*   **Навіщо:** для газетного стилю.
*   **Крок:** Виділити текст -> `Формат` -> `Колонки` -> Обрати кількість.
*   **Додатково:** `Інші параметри` для додавання лінії між колонками.

#### 3. Колонтитули та Нумерація
*   **Верхній/Нижній:** Подвійний клік у верхній або нижній частині сторінки.
*   **Нумерація:** `Вставити` -> `Номери сторінок`. Наголосити на опції "Перша сторінка відрізняється".

### IV. Практичне завдання (15 хв)
Створення макета "Міні-газети":
*   **Джерело тексту:** Скопіюйте текст зі статті [Вікіпедії "Інформаційні технології"](https://uk.wikipedia.org/wiki/Інформаційні_технології).
1.  Перша сторінка: Книжкова, заголовок, текст у 2 колонки.
2.  Друга сторінка (новий розділ): Альбомна, вставлена таблиця або зображення.
3.  На всіх сторінках: Номер сторінки та назва газети у колонтитулі.

### V. Підсумки та ДЗ (5 хв)
*   Рефлексія: "Який інструмент здався найскладнішим?".
*   ДЗ: Створити шаблон реферату за зразком.
