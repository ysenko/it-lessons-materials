## 🤔 Запит чи фільтр?

<div class="grid-container">
<div class="card text-left text-medium-small">

### 🧹 Фільтр

- працює в межах **однієї таблиці**;
- показує **всі поля** таблиці;
- діє **тимчасово**, поки його не очистили.

</div>
<div class="card text-left text-medium-small">

### ❓ Запит

- може поєднувати **кілька зв'язаних таблиць**;
- показує лише **потрібні поля**;
- **зберігається** в базі як окремий об'єкт;
- може **обчислювати** та **змінювати** дані.

</div>
</div>

<div class="important-to-remember text-medium-small text-left">

💡 **Запит** — звернення до бази даних, щоб отримати потрібні дані у вигляді таблиці.

</div>

---

## 🗂️ Типи запитів

<div class="grid-container">
<div class="card text-left text-medium-small">

### 👀 Не змінюють дані

- **На вибірку** — відбирає потрібні поля й записи.
- **З параметром** — умову вводить користувач під час запуску.
- **Перехресний** — підсумовує дані у вигляді таблиці-матриці.

</div>
<div class="card text-left text-medium-small">

### ✏️ Запити на дії

- **Створення таблиці**
- **Оновлення**
- **Доповнення**
- **Знищення**

</div>
</div>

<div class="important-to-remember text-medium-small text-left">

⚠️ Результат запиту на дії **не можна скасувати**! Тому спочатку створюють запит на вибірку, перевіряють результат, і лише потім змінюють тип запиту.

</div>

## 🛠️ Конструктор запитів

<div class="text-medium-small">

**Створити → Конструктор запитів** → додайте таблиці → **двічі клацніть** потрібні поля

| Поле: | Прізвище | Ім'я | Захоплення |
|---|---|---|---|
| **Таблиця:** | Учні | Учні | Учні |
| **Сортування:** | за зростанням | | |
| **Відображення:** | ✅ | ✅ | ✅ |
| **Критерії:** | | | "музика" |
| **Або:** | | | |

</div>

<div class="important-to-remember text-medium-small text-left">

▶️ Запуск — кнопка **Виконати (!)** · 💾 Збереження — **Ctrl+S** · ↩️ Повернутися до бланка — **Вигляд → Конструктор**

</div>

## 🎛️ Як записати умову

<div class="text-medium-small">

| Умова | Що означає |
|---|---|
| `"спорт"` | дорівнює тексту «спорт» (текст — **у лапках**) |
| `>=175` | більше або дорівнює 175 |
| `<6` | менше за 6 |
| `Like "К*"` | починається на «К» |
| `[Введіть захоплення]` | **параметр** — Access попросить ввести значення |

</div>

<div class="grid-container">
<div class="card text-left text-small">

🔗 Умови в **одному рядку** *Критерії* — це **І** (виконуються всі одночасно).

</div>
<div class="card text-left text-small">

🔀 Умова в рядку **Або** — це **АБО** (достатньо однієї).

</div>
</div>

## 🧙 Майстер запитів

<div class="grid-container">
<div class="card text-left text-medium-small">

**Створити → Майстер запитів**

- **Майстер простих запитів** — обираємо таблицю та поля кнопками `>` і `>>`;
- **Майстер перехресних запитів** — обираємо рядки, стовпці та функцію для значень.

</div>
<div class="card text-left text-medium-small">

🧑‍💻 **Режим SQL** — той самий запит, записаний мовою SQL:

```sql
SELECT Прізвище, [Ім'я], Захоплення
FROM Учні
WHERE Захоплення = "музика";
```

</div>
</div>

<div class="important-to-remember text-small text-left">

💡 Майстер створює лише прості запити **без умов**. Умови та сортування додаємо потім у **Конструкторі**.

</div>
