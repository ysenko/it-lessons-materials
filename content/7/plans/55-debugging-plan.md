### 3. Інструктаж до практичної роботи (3 хв)

Учитель пояснює:

1. **Що таке налагодження (debugging)** — процес пошуку та виправлення помилок у програмі. Назва походить від реального жука (bug), якого знайшли в комп'ютері у 1947 р.
2. **Три типи помилок у Python:**
   - **Синтаксичні (SyntaxError)** — Python не може навіть запустити код (неправильний синтаксис).
   - **Виконання (Runtime errors)**: `NameError`, `TypeError`, `IndexError`, `ValueError` — помилка виникає під час роботи програми.
   - **Логічні** — програма запускається, але дає неправильний результат.
3. **Покроковий налагоджувач у Thonny**: кнопка "Debug" (Ctrl+F5), кнопки "Step over" (F6) та "Step into" (F7), панель "Variables" для спостереження за значеннями змінних.

**Завдання 4. Логічна помилка — пошук за допомогою налагоджувача**

Програма запускається без помилок, але дає неправильний результат. Використайте налагоджувач Thonny (Ctrl+F5), щоб знайти проблему:
```python
# Програма рахує суму цифр числа 123
n = 123
hundreds = n % 100     # має бути: n // 100
tens = n % 10 // 10    # має бути: n % 100 // 10
units = n % 10
total = hundreds + tens + units
print("Сума цифр:", total)  # має бути 6
```

Знайдіть помилки та виправте програму.

**Завдання 5. Додаткове (для оцінки 10–12)**
