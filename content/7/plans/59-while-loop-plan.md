### 4. Вивчення нового матеріалу (17 хв)

**4.1. Поняття циклу (2 хв)**

Ключові терміни:
- **Цикл** — структура управління, яка повторює блок інструкцій.
- **Умова циклу** — вираз, що перевіряється перед кожним повторенням.
- **Тіло циклу** — блок коду, що виконується при кожному повторенні.
- **Ітерація** — одне виконання тіла циклу.

---

**4.2. Форма `while` (8 хв)**

Синтаксис:
```python
while умова:
    # тіло циклу
```

Алгоритм виконання:
1. Перевіряється умова.
2. Якщо `True` — виконується тіло, повертаємося до кроку 1.
3. Якщо `False` — цикл завершується, виконання продовжується далі.

**Приклад 1 — «Лічильник від 1 до 5»:**
```python
count = 1
while count <= 5:
    print(count)
    count = count + 1
print("Готово!")
```

Розбір на дошці по кроках: що відбувається при `count = 1`, `2`, ... `5`, `6`.

Ключова думка: `count = count + 1` — обов'язкове оновлення лічильника, інакше цикл ніколи не зупиниться.

**Приклад 2 — «Вгадай число»:**
```python
secret = 7
guess = int(input("Вгадай число від 1 до 10: "))
while guess != secret:
    print("Не вгадав! Спробуй ще раз.")
    guess = int(input("Вгадай число від 1 до 10: "))
print("Правильно! Це число", secret)
```

**Нескінченний цикл та `break`:**

Якщо умова ніколи не стає `False`:
```python
# УВАГА: нескінченний цикл!
x = 1
while x > 0:
    print(x)
    # x не змінюється!
```

Зупинити в Thonny: кнопка **Stop** або `Ctrl+C`.

Оператор `break` — примусовий вихід з циклу:
```python
while True:
    answer = input("Введіть 'стоп' для виходу: ")
    if answer == "стоп":
        break
    print("Ви ввели:", answer)
print("Програма завершена.")
```

**4.3. Форма `while...else` (5 хв)**

Python має особливу форму, якої майже немає в інших мовах:

```python
while умова:
    # тіло циклу
else:
    # виконується ОДИН РАЗ після природного завершення циклу
    # НЕ виконується, якщо цикл зупинено через break
```

**Приклад 1 — базова демонстрація:**
```python
count = 1
while count <= 3:
    print(count)
    count = count + 1
else:
    print("Цикл завершено!")
```

**Приклад 2 — «Три спроби входу»:**
```python
password = "python123"
attempts = 3
while attempts > 0:
    entered = input("Введіть пароль: ")
    if entered == password:
        print("Вхід виконано!")
        break
    attempts = attempts - 1
    print(f"Неправильно. Залишилось спроб: {attempts}")
else:
    print("Обліковий запис заблоковано.")
```

Ключове порівняння: якщо пароль вірний — `break` → `else` **не виконується**. Якщо всі спроби вичерпано — `else` **виконується**.

---

**4.4. Типові помилки та налагодження (2 хв)**

| Помилка | Симптом | Виправлення |
|---|---|---|
| Відсутнє оновлення лічильника | Нескінченний цикл | Додати `count = count + 1` в тіло |
| Відсутній відступ тіла | `IndentationError` | 4 пробіли або Tab |
| Умова завжди `True` | Нескінченний цикл | Перевірити логіку умови |
| Відсутня `:` після `while` | `SyntaxError` | Додати `:` |
