### 3. Мотивація та вивчення нового матеріалу (12 хв)

**Мотивація (1 хв):**
Постановка проблеми: «Ми вміємо порівнювати значення і отримувати `True`/`False`. Але як змусити програму *робити різні речі* залежно від умови?» — саме для цього існує оператор `if`.

**3.1. Проста форма `if` (3 хв)**

Синтаксис:
```python
if умова:
    # блок коду (виконується, якщо умова True)
```

Ключові правила:
- Після `if` — двокрапка `:`.
- Тіло оператора — обов'язковий відступ (4 пробіли або Tab).
- Якщо умова `False` — блок пропускається.

Приклад:
```python
age = int(input("Введіть вік: "))
if age >= 18:
    print("Ви повнолітній!")
print("Програма завершена.")
```

**3.2. Форма `if...else` (3 хв)**

Синтаксис:
```python
if умова:
    # виконується, якщо умова True
else:
    # виконується, якщо умова False
```

Приклад — «Парне чи непарне число?»:
```python
num = int(input("Введіть число: "))
if num % 2 == 0:
    print("Число парне")
else:
    print("Число непарне")
```

**3.3. Форма `if...elif...else` (4 хв)**

Синтаксис:
```python
if умова_1:
    # якщо умова_1 True
elif умова_2:
    # якщо умова_2 True (і умова_1 False)
elif умова_3:
    # якщо умова_3 True (і попередні False)
else:
    # якщо жодна умова не виконалась
```

Приклад — «Оцінка за балами»:
```python
score = int(input("Введіть бал (0-100): "))
if score >= 90:
    print("Відмінно")
elif score >= 75:
    print("Добре")
elif score >= 60:
    print("Задовільно")
else:
    print("Незадовільно")
```

Наголосити: умови перевіряються **зверху вниз**, виконується **тільки перший** збіг.

**3.4. Типові помилки та налагодження (1 хв)**

| Помилка | Що не так | Виправлення |
|---|---|---|
| `if age = 18:` | `=` замість `==` | `if age == 18:` |
| Відсутній відступ тіла | `IndentationError` | Додати 4 пробіли |
| Відсутня `:` | `SyntaxError` | Додати `:` після умови |
