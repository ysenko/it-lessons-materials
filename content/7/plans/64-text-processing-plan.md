### 4. Вивчення нового матеріалу (18 хв)

#### 4.1. Тип даних `str` (3 хв)
Рядок — послідовність символів у лапках (одинарних, подвійних або потрійних).
```python
name = "Аліса"
city = 'Київ'
poem = """Реве та стогне
Дніпр широкий"""
print(type(name))  # <class 'str'>
```
Конкатенація: `"Привіт" + ", " + name`
Повторення: `"ха" * 3` → `"хахаха"`

#### 4.2. Індекси в рядках (4 хв)
Кожен символ має порядковий номер — **індекс**, що починається з `0`. Від'ємні індекси відраховуються з кінця.
```python
s = "Python"
print(s[0])   # P
print(s[1])   # y
print(s[-1])  # n
print(s[-2])  # o
```
Наочна таблиця:
```
 P   y   t   h   o   n
 0   1   2   3   4   5
-6  -5  -4  -3  -2  -1
```

#### 4.3. Escape-послідовності (3 хв)

| Послідовність | Значення |
|:---:|:---|
| `\n` | Новий рядок |
| `\t` | Табуляція |
| `\'` | Одинарна лапка |
| `\"` | Подвійна лапка |
| `\\` | Зворотний слеш |

```python
print("Рядок 1\nРядок 2")
print("Він сказав:\t\"Привіт!\"")
print("Шлях: C:\\Users\\User")
```

#### 4.4. Зрізи / slices (4 хв)
Синтаксис: `рядок[початок:кінець:крок]` (кінець не включається)
```python
s = "Інформатика"
print(s[0:6])    # Інформ
print(s[6:])     # атика
print(s[:6])     # Інформ
print(s[::2])    # Іфрмтк
print(s[::-1])   # акитамрофнІ
```

#### 4.5. Функції `len()`, `ord()`, `chr()` (4 хв)
```python
# len() — довжина рядка
print(len("Привіт"))  # 6
print(len(""))        # 0

# ord() — числовий Unicode-код символу
print(ord("A"))   # 65
print(ord("а"))   # 1072

# chr() — символ за кодом
print(chr(65))    # A
print(chr(1072))  # а

# Корисне застосування: наступна літера в алфавіті
letter = "А"
print(chr(ord(letter) + 1))  # Б
```
