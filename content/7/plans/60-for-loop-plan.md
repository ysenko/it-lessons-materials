### 3. Мотивація та вивчення нового матеріалу (12 хв)

**3.1. Мотивація (2 хв)**

Постановка проблеми: «Ми вже вміємо використовувати `while`. Але що, якщо ми заздалегідь знаємо точну кількість повторень? Чи є спосіб записати цикл коротше і зрозуміліше?»

Порівняння на дошці:
```python
# while — потрібно вручну вести лічильник
count = 1
while count <= 5:
    print(count)
    count = count + 1

# for — лічильник автоматичний!
for count in range(1, 6):
    print(count)
```
Висновок: `for` лаконічніший, коли кількість ітерацій відома наперед.

---

**3.2. Синтаксис циклу `for` (3 хв)**

```python
for змінна in послідовність:
    # тіло циклу
```

- `змінна` — отримує значення кожного елемента послідовності по черзі.
- `послідовність` — рядок, список або результат `range()`.
- Тіло — з відступом 4 пробіли або Tab.
- Цикл завершується автоматично, коли елементи вичерпано.

Швидкий приклад для наочності (показати поруч з синтаксисом):
```python
for letter in "Python":
    print(letter)   # P  y  t  h  o  n
```

---

**3.3. Функція `range()` (5 хв)**

| Форма | Значення | Приклад |
|---|---|---|
| `range(stop)` | від 0 до stop–1 | `range(5)` → 0,1,2,3,4 |
| `range(start, stop)` | від start до stop–1 | `range(1, 6)` → 1,2,3,4,5 |
| `range(start, stop, step)` | від start, крок step | `range(0, 10, 2)` → 0,2,4,6,8 |

Ключова деталь: **кінцеве значення не включається!**

```python
# Числа від 1 до 5:
for i in range(1, 6):
    print(i)        # 1 2 3 4 5

# Парні числа від 0 до 10:
for i in range(0, 11, 2):
    print(i)        # 0 2 4 6 8 10
```

---

**3.4. Коли використовувати `for`, а коли `while` (2 хв)**

Ключове правило: **`for`** — кількість повторень відома наперед; **`while`** — повторюємо, доки виконується умова.

Порівняння на прикладах:
```python
# for — таблиця множення (рівно 10 рядків):
for i in range(1, 11):
    print(f"3 × {i} = {3*i}")

# while — «Вгадай число» (кількість спроб невідома):
secret = 7
guess = int(input("Введи: "))
while guess != secret:
    guess = int(input("Ще раз: "))
```

**Завдання 1 — Таблиця множення** *(Середній рівень)*

Напиши програму:
1. Запитати число від 1 до 9: `n = int(input("Введіть число: "))`.
2. За допомогою `for` та `range()` вивести таблицю множення для цього числа (від ×1 до ×10).

Приклад виводу для `n = 3`:
```
3 × 1 = 3
3 × 2 = 6
...
3 × 10 = 30
```

Очікуване рішення:
```python

for i in range(1, 11):
    print(f"{n} × {i} = {n * i}")
```

**Завдання 2 — Сума парних чисел** *(Достатній рівень)*

Напиши програму:
1. Запитати натуральне число N.
2. За допомогою `for` та `range()` обчислити суму всіх парних чисел від 0 до N включно.
3. Вивести результат.

Приклад виводу для `N = 10`:
```
Сума парних від 0 до 10 = 30
```

Очікуване рішення:
```python
n = int(input("Введіть N: "))
total = 0
for i in range(0, n + 1, 2):
    total = total + i
print(f"Сума парних від 0 до {n} = {total}")
```

**Завдання 3 — Ромб зірочок** *(Високий рівень ⭐)*

Приклад для `N = 5`:
```
*
***
*****
***
*
```

Очікуване рішення:
```python
n = int(input("Введіть непарне число N: "))
for i in range(1, n + 1, 2):
    print("*" * i)
for i in range(n - 2, 0, -2):
    print("*" * i)
```
