### 3. Вивчення нового матеріалу (20 хв)

#### 3.1. Тип даних `bool` (4 хв)

Логічний тип `bool` — особливий тип даних, що може приймати лише два значення: `True` (істина) або `False` (хибність). Результатом будь-якого порівняння є значення типу `bool`.

```python
print(type(True))    # <class 'bool'>
print(5 > 3)         # True
print(5 < 3)         # False
```

#### 3.2. Оператори порівняння (6 хв)

| Оператор | Значення |
|:---:|:---|
| `==` | Рівно |
| `!=` | Не рівно |
| `>` | Більше |
| `<` | Менше |
| `>=` | Більше або рівно |
| `<=` | Менше або рівно |

Приклади з числами та рядками:
```python
age = 16
print(age >= 18)          # False

print("apple" < "banana") # True  (лексикографічне порівняння)
print("A" < "a")          # True  (A=65, a=97 за Unicode)
print("5" == 5)           # False (рядок ≠ число!)
```

#### 3.3. Логічні оператори `and`, `or`, `not` (7 хв)

| Оператор | Значення | Коли `True` |
|:---:|:---|:---|
| `and` | І | Коли обидві умови `True` |
| `or` | АБО | Коли хоча б одна умова `True` |
| `not` | НЕ | Інвертує: `True` → `False` |

```python
temp = 25
print(temp >= 20 and temp <= 30)  # True
print(temp < 0 or temp > 35)     # False
print(not True)                   # False
```

Побутові аналогії для пояснення:
- `and`: «Піду гуляти, якщо закінчу уроки **і** не буде дощу».
- `or`: «Підемо в кіно **або** в театр».
- `not`: «**Не** дощ → беру велосипед».

#### 3.4. Перетворення логічних значень (3 хв)

«Хибні» (falsy) значення — ті, що перетворюються на `False`:

```python
print(bool(0))       # False
print(bool(0.0))     # False
print(bool(""))      # False
print(bool("False")) # True  ← НЕ порожній рядок!

print(int(True))     # 1
print(int(False))    # 0
print(True + True)   # 2
print(str(True))     # 'True'
```
