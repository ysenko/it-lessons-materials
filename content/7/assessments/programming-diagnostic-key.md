## Критерії оцінювання описових завдань

**Завдання 5.** Програма-калькулятор площі трикутника.

Еталонний розв'язок:
```python
base = float(input("Введи основу трикутника: "))
height = float(input("Введи висоту трикутника: "))
area = 0.5 * base * height
print("Площа трикутника =", area)
```

- Правильне зчитування даних через `input()` з перетворенням у `float` — **1 бал**
- Правильна формула обчислення площі — **1 бал**
- Правильний вивід результату — **1 бал**

**Завдання 10.** Таблиця множення числа.

Для числа n = 3 перші три рядки:

```
3 × 1 = 3
3 × 2 = 6
3 × 3 = 9
```

- Правильні перші три рядки виводу — **1 бал**
- `range(1, 11)` — перебирає значення від 1 до 10 включно — **1 бал**
- `n * i` — множить введене число на поточне значення лічильника — **1 бал**

**Завдання 15.** Логічна помилка у програмі підрахунку суми.

- `total` після виконання для N = 4 матиме значення **4** (присвоюється останнє значення `i`) — **1 бал**
- Виправлення: замінити `total = i` на `total = total + i` — **1 бал**
- Правильна сума чисел від 1 до 4 = **10** — **1 бал**

**Завдання 20.** Програма-генератор надійного пароля.

Еталонний розв'язок:
```python
import random
import string

chars = string.ascii_letters + string.digits
password = ""
for i in range(8):
    password = password + random.choice(chars)
print("Ваш пароль:", password)
```

- Імпортовано обидва модулі та правильно сформовано рядок `chars` — **1 бал**
- Цикл `for` з `range(8)` правильно будує рядок пароля — **1 бал**
- Програма запускається без помилок і виводить пароль із 8 символів — **1 бал**
