## Критерії оцінювання описових завдань

**Завдання 20.** Самостійно напиши програму-генератор надійного пароля.

Еталонний розв'язок:
```python
import random
import string

chars = string.ascii_letters + string.digits
password = ""
for i in range(8):
    password = password + random.choice(chars)
print("Ваш пароль:", password)
```

- Імпортовано обидва модулі (`import random`, `import string`) та правильно сформовано рядок `chars` — **1 бал**
- Цикл `for` з `range(8)` правильно будує рядок пароля (додає символи) — **1 бал**
- Програма запускається без помилок і виводить пароль із 8 символів — **1 бал**
