# НУШ Lesson Planner

Цей навик допомагає вчителю інформатики планувати уроки відповідно до стандартів НУШ та створювати презентації Marp на основі шаблону Gaia.

## Робочий процес

### Фаза 1: Збір вхідних даних
Запитайте у користувача наступну інформацію, якщо вона не була надана:
1. **Номер уроку** (наприклад, "01").
2. **Тема уроку** (наприклад, "Інформаційні процеси").
3. **Клас** (5–12).
4. **Додаткові обмеження або побажання** (наприклад, "фокус на практичну роботу", "вступний урок").

### Фаза 2: Складання плану уроку
1. Створіть детальний план уроку **виключно українською мовою**, дотримуючись структури з `references/lesson-structure.md`.
2. Представте план користувачеві для перегляду.
3. Проведіть ітерації та внесіть правки, поки користувач не підтвердить, що він задоволений планом.
4. Після підтвердження збережіть план у файл:
   `content/<клас>/plans/<номер>-<тема-slug>-plan.md`
   *(Замініть `<тема-slug>` на транслітеровану назву теми, наприклад `info-processes`)*.

### Фаза 3: Генерація презентації Marp
1. Прочитайте шаблон `templates/gaia_template.md`.
2. Трансформуйте затверджений план уроку в презентацію Marp.
3. Використовуйте CSS-класи з шаблону для оформлення (див. `references/marp-mapping.md` для підказок):
   - `.grid-container` для порівнянь або тексту з картинкою.
   - `.task` для практичних завдань.
   - `.card` для виділення важливих понять.
   - `.important-to-remember` для ключових правил.
4. Замініть плейсхолдери у шаблоні:
   - `<REPLACE-WITH-ACTUAL-GRADE>` -> номер класу.
   - `REPLACE WITH LESSON NUMBER` -> номер уроку.
   - `REPLACE WITH LESSON TITLE` -> тема уроку.
5. Представте презентацію користувачеві. Проведіть ітерації, поки користувач не буде задоволений.
6. Збережіть презентацію у файл:
   `content/<клас>/<номер>-<тема-slug>.md`.

## Важливі примітки
- **Мова:** Весь контент (план та презентація) має бути українською мовою.
- **Стиль:** Презентація має бути візуально привабливою, структурованою та містити інтерактивні елементи (емодзі, посилання на вправи).
- **Стурктура:** Завжди перевіряйте наявність обов'язкових розділів (мета, хід уроку, ДЗ).
