# Відображення контенту плану на слайди Marp (Gaia)

Цей документ допоможе вам правильно використовувати CSS-класи шаблону Gaia при створенні презентації.

## 1. Титульний слайд
- **Заголовок:** `# Тема уроку`
- **Підзаголовок:** `## 🏫 Урок **Номер**`
- **Плейсхолдери:** Обов'язково замініть `<REPLACE-WITH-ACTUAL-GRADE>`, `<REPLACE-WITH-ACTUAL-LESSON-NUMBER>`, `REPLACE WITH LESSON NUMBER`, `REPLACE WITH LESSON TITLE`.

## 2. Слайд "🛡️ Пригадуємо: техніка безпеки"
- Успадковується з шаблону без змін, одразу після титульного слайда.
- **Не редагуйте, не видаляйте та не переносьте цей слайд** — його вміст однаковий для всіх уроків та класів.

## 3. Слайд "Сьогодні ми дізнаємося" (Цілі)
- Використовуйте `🎯` як емодзі в заголовку.
- Використовуйте маркований список з емодзі (`ℹ️`, `🔧`, `✏️`).

## 4. Слайди з теорією
- Використовуйте `.card` для визначень.
- Використовуйте `.important-to-remember` для правил або застережень.
- Використовуйте `.grid-container` для порівняння двох об'єктів або тексту поруч із зображенням.

## 5. Практичні завдання
Зміст, кількість слайдів і правила оцінювання — у `SKILL.md`, розділ «Обов'язкові правила змісту». Тут лише оформлення.

**Завдання 1 — закріплення теорії** (`.task`):
- Заголовок `## 🧩 Завдання 1: <коротка назва>`, 1–3 рядки інструкції для учнів і реальне посилання:
  - Padlet: `🔗 [Відкрити дошку](<посилання>)`
  - Classtime: `🔗 [Приєднатися до сесії](<посилання>)` + `🔑 Код: **<код>**`
  - LearningApps: `🔗 [Відкрити вправу](<посилання>)`

```html
<section class="task">

## 🧩 Завдання 1: Розподіліть поняття

Відкрийте дошку та перетягніть кожну картку у правильну колонку.

🔗 [Відкрити дошку](https://padlet.com/...)

</section>
```

**Завдання 2 — робота за комп'ютером** (`.task`):
- Два слайди, кожен у власному `<section class="task">` (розрив `---` — між секціями, ніколи всередині).
- Слайд 1: `## ⌨️ Завдання 2: <коротка назва>` з підзаголовками `### 🟢 Середній` і `### 🟡 Достатній`.
- Слайд 2: `## ⌨️ Завдання 2 (продовження)` з підзаголовком `### 🔴 Високий`.

## 6. Домашнє завдання
- Заголовок `## 🏠 Домашнє завдання`; останній слайд презентації.

## Використання CSS-класів
Приклад використання класу:
```html
<section class="task">

## ⌨️ Завдання 2: <коротка назва>
1. Відкрийте програму...
2. Створіть...

</section>
```

Для сітки (grid):
```html
<section class="grid-container">
<div class="text-left text-medium">

Тут опис завдання або теоретичний текст.

</div>
<div class="image-center">

![w:300px](./assets/path/to/image.png)

</div>
</section>
```
