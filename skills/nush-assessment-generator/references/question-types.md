# Типи завдань для платформи Classtime

Цей документ описує типи завдань, сумісних з платформою Classtime, та їх прив'язку до рівня складності.

---

## Рівень: Простий

### Одиничний вибір (Single Choice)
Учень обирає **одну** правильну відповідь з 4 варіантів.

**Використання:** перевірка знання визначень, фактів, базових понять.

**Формат у Markdown:**
```
**Запитання 1.** [Текст запитання]

- A) [варіант]
- Б) [варіант]
- В) [варіант ✓]
- Г) [варіант]
```

---

## Рівень: Середній

### Множинний вибір (Multiple Choice)
Учень обирає **кілька** правильних відповідей (зазначте, скільки саме).

**Використання:** перевірка розуміння, класифікації, переліків ознак.

**Формат у Markdown:**
```
**Запитання 2.** [Текст запитання] *(оберіть усі правильні варіанти)*

- [ ] A) [варіант ✓]
- [ ] Б) [варіант]
- [ ] В) [варіант ✓]
- [ ] Г) [варіант]
- [ ] Д) [варіант ✓]
```

### Заповнення пропусків (Fill in the Blank)
Учень вписує пропущене слово або фразу в текст.

**Використання:** перевірка знання термінів, формул, назв.

**Формат у Markdown:**
```
**Запитання 3.** Заповніть пропуски:

Пристрій, що виконує програму та керує іншими компонентами комп'ютера, називається ___________.
Він складається з ___________ та ___________.
```

### Зіставлення (Matching)
Учень з'єднує поняття з відповідними визначеннями або прикладами.

**Використання:** перевірка розуміння зв'язків між поняттями.

**Формат у Markdown:**
```
**Запитання 4.** Зіставте поняття з їх визначеннями:

| Поняття | Визначення |
|---------|------------|
| A. Алгоритм | 1. Набір правил для вирішення задачі за скінченну кількість кроків |
| Б. Змінна | 2. Поіменоване місце в пам'яті для зберігання даних |
| В. Цикл | 3. Повторення блоку інструкцій певну кількість разів |

*Відповіді: A–1, Б–2, В–3*
```

---

## Рівень: Складний

### Коротка описова відповідь (Short Answer)
Учень формулює відповідь власними словами (2–5 речень).

**Використання:** перевірка розуміння на глибокому рівні, застосування знань у нових ситуаціях, аналіз і оцінювання. Відповіді перевіряє вчитель вручну за критеріями.

**Формат у Markdown:**
```
**Запитання 5.** [Текст запитання, що вимагає пояснення або аналізу]

*Місце для відповіді:*
_______________________________________________
_______________________________________________
_______________________________________________

*Критерії оцінювання:*
- [критерій 1 — 1 бал]
- [критерій 2 — 1 бал]
- [критерій 3 — 1 бал]
```

---

## Розподіл типів за рівнем складності (рекомендований)

| Рівень | Типи завдань | Частка в тесті |
|--------|-------------|----------------|
| Простий | Одиничний вибір | ~40% |
| Середній | Множинний вибір, Заповнення пропусків, Зіставлення | ~40% |
| Складний | Коротка описова відповідь | ~20% |

> Для діагностувальних робіт збільшуйте частку простих завдань до 60%, щоб виявити базові прогалини.
> Для квізів використовуйте лише одиничний та множинний вибір, уникаючи описових відповідей.
